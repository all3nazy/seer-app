# سِير | SEER

منصة تشغيل المدارس الأهلية والحضانات — **شغلك يسير.**

## التشغيل محليًا

```bash
npm install
cp .env.example .env.local
npm run dev
```

أضف متغيرات Supabase في `.env.local`، وشغّل ترحيل قاعدة البيانات `supabase/migrations/0001_core.sql` في مشروع Supabase الخاص بك بعد مراجعته.

## حالة التطوير
- واجهة تأسيسية عربية متجاوبة (ليست لوحة بيانات فعلية بعد).
- هيكل Next.js + TypeScript.
- جداول تأسيسية وسياسات RLS للقراءة فقط؛ لا توجد سياسات كتابة بعد عمدًا.
- لم تُفعّل المصادقة أو المدفوعات أو WhatsApp أو إرسال الإشعارات.
- قبل الإنتاج: استكمال ربط الهوية والصلاحيات، ضمان تطابق معرفات المؤسسة عبر العلاقات، اختبارات العزل، وسياسات الكتابة.
